## prompt设计过程
-创建一个网页来帮我写生日贺卡（Goal）
-当我提供一个人的姓名，年龄，爱好时（Input），它应该会给我返回一条有趣的消息（Output）

如果不满意，接着prompt，沉浸在vibe coding的氛围中
-加上节日风格的标题和配色，让它更好看一些
-把卡片放在右侧展示，让他看起来像生日贺卡的内页 （Layout-布局）
-在页面顶部加一个有趣标题，另外，不要替换旧卡片，而是保留他们并叠放在新卡片下方(features)
当我们用ai写代码的时候，通常从一组基本指令开始
prompt基本块
Goal+Input+Output+Layout+Features
